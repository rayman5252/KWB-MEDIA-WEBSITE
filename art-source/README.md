# Original game art (not deployed)

Full-quality PNG originals of the game sprites. The live games load the
WebP copies in each game's `assets/` folder; this folder is listed in
`.vercelignore`, so it stays in GitHub but is never uploaded to Vercel.

If you change a sprite, edit the PNG here, then export a WebP of the same
size into the matching `assets/` folder (quality ~90 keeps it sharp).
