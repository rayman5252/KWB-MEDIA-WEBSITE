# BLOG PHOTOS

Drop photos here and the blog robot will use them as post header images.

## How to add photos (from any browser)

1. Open this folder on GitHub (you're probably looking at it right now).
2. Click **Add file** (top right) → **Upload files**.
3. Drag your photos onto the page.
4. Scroll down and click the green **Commit changes** button. Done.

## Tips

- **Horizontal (landscape) photos work best.**
- Any size is fine up to 25 MB each. The robot makes a web-sized copy when it uses one.
- Nice-to-have: a descriptive file name like `drone-farm-sunrise.jpg`. Not required.
- **This repo is public.** Only upload photos you're OK with anyone seeing.
  Skip anything a client would consider confidential, and people who haven't agreed to be shown.
- Photos in this folder are NOT put on the website by themselves. Only the ones picked for a post get published.
